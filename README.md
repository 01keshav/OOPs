# OOP in Java - Complete Course

A free study site for **course 105303: Object-Oriented Programming in Java**. It covers 6 units and 47 topics, explained step by step with examples, diagrams and practice questions. Built for exam preparation and for making your own notes.

**Live site:** https://01keshav.github.io/OOPs/

## Contents

| Unit | Topics |
|------|--------|
| 1. OOP Concepts and Java Basics | History, procedural vs OOP, JDK/JRE/JVM, data types, operators, control structures, first program |
| 2. Objects, Classes and Constructors | Class, object, methods, array of objects, constructors, method binding, static, access modifiers, `this`, garbage collection, inner classes, String |
| 3. Inheritance, Interfaces and Packages | Inheritance and its types, `super`, `final`, overloading, overriding, abstraction, interfaces, IS-A vs HAS-A, encapsulation, packages |
| 4. Exception Handling | Error vs exception, try/catch/finally, throw vs throws, multiple catch, custom exceptions |
| 5. Multithreading | Process vs thread, creating threads, lifecycle, priority, synchronization, inter-thread communication |
| 6. Files, Collections and JDBC | File streams, File class, Collections framework, List/Set/Queue/Map, JDBC |

## Features

- **Complete lessons:** every topic has a definition, each type or part explained in its own section, code with real output, uses, advantages, limitations and common mistakes
- **Animated diagrams** for inheritance, hierarchies, flows and lifecycles
- **Notes tools:** copy a lesson as notes, print or save as PDF, and write your own notes (saved on your device)
- **Quick revision** list at the end of every topic
- **Practice questions** for each topic, with a copy button so you can paste them into your favourite AI
- **Progress tracking:** a topic is saved only when you press "Mark as complete", and you can undo it
- **Dark and light mode** with a neumorphic design
- **Search** and previous/next navigation
- **Mobile friendly**

## Run locally

No install and no build step. It is one HTML file.

1. Clone or download this repository
2. Open `index.html` in any browser

```bash
git clone https://github.com/01keshav/OOPs.git
cd OOPs
```

## Tech

Plain HTML, CSS and JavaScript in a single file. Progress, notes and theme are stored in your browser's `localStorage`. Nothing is sent to any server.

## Contributing

Contributions are welcome.

2. Create a branch: `git checkout -b fix/topic-name`
3. Make your change (fix a typo, improve an explanation, add an example, report a wrong output)
4. Commit with a clear message, for example `fix: correct output in Static Members example`
5. Push and open a pull request

Found a bug or a missing topic? Open an issue or a pull request. Please keep Java examples short, make sure they compile, and paste the real output.
